### Corpo 10 (457B-4591), testo originale

```
457B ld iy,c82e      457F ld ix,c49e     4583 call 4592
4586 ld a,00         4588 jr c,458F      458A ld (c466),a     458D ld a,11
458F pop hl          4590 ld (hl),a      4591 ret
```
In C: `IY = c82e`, `IX = c49e`, `sub_4592`; riporto acceso → `tabella[slot] = 0`;
spento → `M(0xc466) = 0`, `tabella[slot] = 0x11`. `sub_4592` dà il riporto
con `NEMICI_PONI_RIPORTO` (acceso se (IY+0C) ha il bit 7, spento negli altri
due esiti, da `grafo symbol sub_4592`).

### Corpo 01 (48D1-4937), testo originale

```
48D1 ld iy,c82e      48D5 ld a,(iy+2C)   48D8 ld b,00        48DA bit 0,a
48DC ld a,16         48DE jr z,48E4      48E0 ld a,FA        48E2 set 0,b
48E4 add a,(iy+15)   48E7 ld l,a         48E8 ld a,(iy+29)   48EB cp 04
48ED ld a,08         48EF jr nz,48F5     48F1 ld a,F8        48F3 set 1,b
48F5 add a,(iy+0E)   48F8 ld h,a         48F9 call 36F0      48FC ld a,(hl)
48FD ld ix,c46e      4901 cp 80          4903 ld hl,c08a     4906 jr nc,4926
4908 set 0,(iy+01)   490C ld (hl),00     490E ld c,01        4910 rst 28
4911 call 49AE       4914 res 0,(iy+01)  4918 pop hl         4919 cp 04
491B jr nz,4924      491D rrc b          491F jr nz,4924     4921 ld (hl),25
4923 ret             4924 ld (hl),a      4925 ret
4926 cp F8           4928 ld c,02        492A jr c,492E      492C ld c,09
492E rst 28          492F ld (hl),00     4931 call 4938      4934 pop hl
4935 ld (hl),02      4937 ret
```
Fatti che il C deve rispettare:
- **Registri in ingresso a 49AE e 4938**: A = valore della cella, E = indice
  della cella e D = 0 (da `sub_36f0`: `z->a = a; SET_DE(z, a); SET_HL(z, GRIGLIA_C0BD + a)`),
  B = bit 0/1 impostati a 48E2/48F3, IX = c46e, IY = c82e, HL = c08a, C = 1
  (49AE) o 2/9 (4938). `rst 28` (`sub_0028`, `z80_0xxx.c:379`) accoda il
  suono C e conserva A, B, C, H, L; non tocca D, E, IX, IY. Usare un solo
  `struct z80 z = {0}` per tutto il corpo, con le chiamate nell'ordine
  originale.
- **c08a = 0 prima di 49AE** (490C) e **prima di 4938** (492F, dopo il
  `rst 28`): 49AE lo legge a 4A0D, 4938 a 499D (`POSA_C08A`).
- **Uscita di 49AE**: A = 2, 4 o 1a. Con A = 4 lo slot prende 25 se B = 0
  (`rrc b` dà zero solo per B = 0), altrimenti A. B all'uscita di
  `sub_49ae` è già quello dell'originale: 3 (4A2B), 2 (4A70), 3 o 0 secondo
  (IX+1D) < 7 (4A42-4A48, C a `nemici_comuni.c:394`). Il bit 0 di (IY+1)
  si spegne dopo 49AE e prima dello slot.
- Ramo cella ≥ 80: C = 2 se A < F8, altrimenti 9; slot = 02.
- `pop hl; ld (hl),n; ret` = `tabella[slot] = n; return` (testa di
  `attivita.c`). Esempio di forma: `attivita_11_456e` (`attivita.c:198`).
